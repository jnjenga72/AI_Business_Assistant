# AI Business Assistant

## Overview
An AI-powered business assistant built with Python
and Ollama.

## Features
- Business question answering
- Sales revenue calculations
- Top product identification
- Product revenue lookup
- Conversation history
- AI tool calling

## Technologies
- Python
- Ollama
- Requests
- JSON

## Installation

pip install -r requirements.txt

## Run

python main.py
